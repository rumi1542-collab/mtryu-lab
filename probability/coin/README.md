# 동전 실험실 · 확률 실험실

동전 하나로 "패턴이 있을까?", "많이 던지면 어떻게 될까?"를 몸으로 배우는 게임 4가지예요.
강 건너기가 **주사위 두 개의 합(복합 사건)** 의 분포를 다룬다면, 동전 실험실은 그 앞 단계인 **한 가지 사건의 규칙성(큰 수의 법칙)** 을 다뤄요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `probability/coin/index.html` | 게임 4가지·순위표 전체. 이 파일만 열어도 실행돼요. (순위는 그 컴퓨터에만 저장) |
| `api/coin.js` | 순위 기록을 모든 컴퓨터가 함께 쓰게 해 주는 Vercel 서버 함수 |
| `api/_coinlib.js` | `coin.js`가 기록을 검사할 때 쓰는 계산 도구 |

학년도·학교 목록(`/api/config`), 저장소(Upstash Redis), 환경 변수(`KV_REST_API_URL`, `RD_ADMIN_KEY` 등), 이름 검사(`api/_names.js`)는 **강 건너기와 같은 것**을 그대로 써요. 새로 설정할 것은 없어요. 학교·학년도를 늘리려면 강 건너기의 관리자 모드에서 하면 두 게임에 같이 반영돼요.

## 동전과 순위 올리기
- **동전**: 500원짜리 학(鶴) 동전이에요. **그림(학) = 앞면**, **숫자(500) = 뒷면**이고, 그림·숫자 아래에 "앞"/"뒤" 글자가 그림의 1/3 크기로 들어가 있어요. 학 그림은 `index.html`의 `<symbol id="crane">`이에요.
- **이름은 처음 화면에서 먼저** 써요. 이름이 없거나 쓸 수 없는 말이 들어 있으면 게임이 시작되지 않아요.
- **순위는 자동으로 올라가요.** 게임이 끝나면 저절로 저장되고 "N위로 올라갔어요"가 보여요. 저장에 실패하면 "다시 저장하기" 버튼이 나와요. ("내가 만든 배열 판정"은 순위가 없어요.)

## 게임 4가지

| # | 게임 | 배우는 것 | 순위 기준 |
|---|---|---|---|
| 1 | **연속 맞추기** | 동전에 패턴은 없다 (매번 1/2) | 맞힌 횟수 (점수: 200 → 400 → 800 …, 최대 30번) |
| 2 | **상대도수 줄타기** | 던진 횟수가 늘면 상대도수가 0.5 근처에 모인다 | 예상과 안정된 횟수의 차이가 작을수록 (범위별 순위표) |
| 3 | **동전 조작 탐정** | 진짜 무작위는 생각보다 덩어리가 길다 | 8문제 중 맞힌 개수 |
| 4 | **내기 시뮬레이터** | 적게 던지면 쏠림이 크고, 많이 던지면 비율이 모인다 | 점수 (최대 120점) |

### 1. 연속 맞추기
앞/뒤를 먼저 고르고 동전이 던져져요. 맞히면 첫 번째는 200점, 그다음부터는 맞힐 때마다 2배가 되고, 한 번 틀리면 끝나요.
끝나면 **내 예측 줄과 실제 결과 줄**이 나란히 보여서 "내가 찾은 패턴이 정말 맞았는지" 볼 수 있어요.
순위표 아래에는 학교 전체의 **맞힌 횟수 분포**(막대)와 이론값(1/2, 1/4, 1/8 …)이 같이 나와요.

### 2. 상대도수 줄타기
1. **예측** (그래프 위의 상자): ① 상대도수 범위(0.40~0.60, 0.45~0.55, 0.48~0.52 중 하나, 처음에는 0.40~0.60)를 고르고, ② "몇 번째 던진 뒤부터 이 범위 밖으로 안 나갈까?"를 예상해요. 던지는 속도도 슬라이더로 고르고, 던지기 시작 버튼을 눌러요. 그래프는 그 아래에 있어요.
2. **첫 번째 실험**: 동전을 1000번 던져 꺾은선그래프가 그려져요. 노란 점선은 내 예측, 분홍 선은 안정된 횟수예요. 결과는 **저절로 순위에 올라가요.**
3. **연습 실험**: "같은 예측으로 한 번 더"를 누르면 같은 조건으로 또 던져요. 이전 선이 흐리게 쌓여서 깔때기 모양이 보이고, 안정된 횟수가 실험마다 달라지는 것을 눈으로 확인해요. **연습 실험은 순위에 올라가지 않아요.**
4. **새로 도전**: "예측 바꿔서 새로 도전"을 누르면 범위와 예상 횟수를 다시 정하고, 그 첫 번째 실험이 다시 순위에 올라가요.

- **안정된 횟수**: 이 횟수 뒤로는 1000번째까지 상대도수가 범위 밖으로 한 번도 나가지 않는 때예요. (1000번 안에 못 들어오면 1001번으로 계산해요.)
- **차이** = |내 예상 횟수 − 안정된 횟수| (+, − 없이). 예) 예측 200번, 안정된 횟수 293번 → 차이 93번. **작을수록 순위가 높아요.** 같으면 먼저 기록한 사람이 위예요.
- 순위표는 **상대도수 범위마다 따로** 있어요. (범위가 넓을수록 일찍 안정되므로 서로 다른 범위는 섞어서 비교하지 않아요.) 순위표에는 이름 · 예상 횟수 · 안정된 횟수 · 차이 · 꺾은선그래프가 보여요.
- 운의 영향: 한 번의 실험이라 운이 섞여요. 그래서 연습 실험으로 "같은 예측도 실험마다 다르다"를 체험하게 했어요.

### 3. 동전 조작 탐정
- **탐정 놀이(순위 있음)**: 40칸짜리 두 배열 중 하나는 진짜 동전, 하나는 사람이 지어낸 것(컴퓨터가 "자주 바꾸고 연속을 피하는" 사람의 습관을 흉내 낸 것)이에요. 8문제를 푸는데 뒤로 갈수록 지어낸 배열이 진짜에 가까워져요. 답을 고르면 앞면 수·가장 긴 연속·바뀐 횟수를 비교해서 보여 줘요.
- **내가 만든 배열 판정(순위 없음)**: 진짜 동전처럼 보이게 앞/뒤를 50번 직접 눌러 만들면, 컴퓨터가 진짜 동전 던지기 3000번과 비교해서 "사람이 만든 것 같아요/구별하지 못했어요"를 알려 줘요.

### 4. 내기 시뮬레이터
"동전 10번 중 앞면 7번 이상" vs "1000번 중 700번 이상"처럼 비율은 같고 횟수만 다른 두 내기를 보여 줘요. 6문제에서
어느 쪽이 더 자주 성공할지 고르고, A 내기의 성공 확률(%)을 예상해요. 그다음 **1000번씩 시험**하는 모습(점 1000개)을 보고 정확한 확률과 비교해요.
점수는 문제마다 선택이 맞으면 10점 + 확률 예상이 가까울수록 최대 10점이에요. (정확한 확률은 이항분포로 계산하므로 운이 점수에 끼어들지 않아요.)
"앞면이 정확히 절반"처럼 **많이 던질수록 오히려 드물어지는 문제**와 "40~60% 사이"처럼 **많이 던질수록 흔해지는 문제**가 섞여 있어요.

## 수업에서 쓰는 순서 (제안)
1 → 2 → 3 → 4 → 강 건너기. "패턴은 없다 → 비율은 모인다 → 그래서 진짜 무작위는 이렇게 생겼다 → 횟수에 따라 달라진다 → 그럼 주사위 두 개의 합은?"으로 이어져요.

## 컴퓨터에서 먼저 돌려 보기
`index.html`을 더블클릭해서 브라우저로 열면 바로 게임이 돼요. 이때 순위는 **그 컴퓨터에만** 저장되고, 시작 화면에 "이 컴퓨터에만 기록이 저장돼요"라고 나와요.

## 잘못된 기록 지우기 (관리자)
`RD_ADMIN_KEY`(강 건너기와 같은 암호)로 지울 수 있어요. `game`은 `run`, `tune10`, `tune5`, `tune2`(줄타기, 범위 0.5±0.10 / 0.05 / 0.02), `spot`, `bet` 중 하나예요. 기록의 `id`는 Upstash 데이터 화면에서 볼 수 있어요.

```
# 한 건
curl -X DELETE "https://내주소/api/coin?game=run&year=2026&school=선운중학교&id=기록id" -H "x-admin-key: 비밀문구"
# 여러 건 (쉼표로, 100건까지)
curl -X DELETE "https://내주소/api/coin?game=run&year=2026&school=선운중학교&ids=a,b,c" -H "x-admin-key: 비밀문구"
# 그 게임의 순위 전체
curl -X DELETE "https://내주소/api/coin?game=run&year=2026&school=선운중학교&all=1" -H "x-admin-key: 비밀문구"
```

## 서버가 확인하는 것, 못 하는 것
- 이름(8글자, 욕설 검사), 학년도·학교(등록된 것만), 값의 범위는 서버가 확인해요. 같은 IP에서 1분에 120번까지만 저장할 수 있어요.
- **점수는 서버가 다시 계산**해요. (연속 맞추기: 배열에서 맞힌 횟수, 줄타기: 던진 결과(1000번)에서 안정된 횟수와 차이, 내기: 정확한 확률로 점수.) 화면에서 보낸 점수는 쓰지 않아요.
- 동전이 정말 무작위로 던져졌는지는 확인하지 못해요. (강 건너기와 같아요.) 동전은 브라우저의 암호용 난수(`crypto.getRandomValues`)로 던져요.
- 조작 탐정의 "맞힌 개수"는 화면의 값을 그대로 받아요.
- 게임마다 학교·학년도당 최대 5000개 기록을 저장해요. (줄타기는 기록 하나가 약 0.4KB예요.)

## 고칠 때 참고
- 계산식은 `index.html`(화면)과 `api/_coinlib.js`(서버)에 같은 내용이 들어 있어요. `settleTime`, `BET`(내기 문제), `betRound`를 고칠 때는 둘을 같이 고쳐 주세요.
- 이름 금지어 목록은 강 건너기와 같이 `index.html`의 `BAD_WORDS`와 `api/_names.js`에 있어요.
- 문제 난이도: 조작 탐정의 지어낸 배열은 `genFake(길이, 바꿀 확률, 연속 상한)`로 만들어요. `newSpotRound()`의 숫자를 바꾸면 쉽거나 어려워져요. 줄타기의 범위는 2·5·10(0.5 ± 0.02, 0.05, 0.10) 세 가지뿐이에요. (서버도 같은 범위만 받아요.)
- `index.html` 맨 위 `CONFIG`의 `years`, `schools`는 서버·저장된 목록이 없을 때 쓰는 **처음 값**이에요.
