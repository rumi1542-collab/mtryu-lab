# 확률 실험 시뮬레이터 · 확률 실험실

내가 직접 **도구와 경우를 정해서** 확률 실험을 만들고, 던져 보며 도수·상대도수를 살펴보는 프로그램이에요.
만든 실험은 우리 학교에 올릴 수 있고, 친구들은 **결과만 보고** "각 경우가 일어날 가능성이 같을까?"를 판단해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `probability/sim/index.html` | 화면 전체 (만들기·실험하기·친구 실험 판정하기). 이 파일만 열어도 만들기·실험하기는 돼요. |
| `api/sim.js` | 올리기·목록·던지기·판정·지우기를 처리하는 Vercel 서버 함수 |
| `api/_simlib.js` | 값 검사와 난수 던지기 도구 |

학년도·학교 목록(`/api/config`), 저장소(Upstash Redis), 이름 검사(`api/_names.js`), 내 정보(`me-sync.js`, `lab-bar.js`)는 강 건너기·동전 실험실과 **같은 것**을 그대로 써요. 새로 넣을 환경 변수는 없어요.

## 사용 흐름

1. **처음 화면**: "각 경우가 발생할 가능성이 동등한 경우" / "동등하지 않은 경우" 중에서 골라요.
2. **도구 만들기**: 도구 이름(예: 정사면체 주사위)을 쓰고 경우를 추가·삭제해요. (2~8개)
   - 동등한 경우: 이름만 써요. 모든 경우의 확률이 똑같이 설정돼요. (처음에 정사면체 1·2·3·4가 채워져 있어요)
   - 동등하지 않은 경우: 경우마다 **상대도수**를 써요. (소수 `0.25` 또는 분수 `1/4`) 합이 1이 아니면 실험을 시작할 수 없고, "마지막 값 채우기" 버튼이 도와줘요. (처음에 압정 0.4 / 0.6이 채워져 있어요)
3. **확률 실험하기** (두 가지)
   - **n번 던지기** (n은 1~10,000): 결과 상자(스크롤) · 도수와 상대도수 표 · 도수 막대그래프 · 던진 횟수에 따른 상대도수 꺾은선그래프
   - **n번씩 k회 반복하기** (n 1~1,000, k 1~1,000, n×k ≤ 200,000): 경우를 하나 고르고, 한 회(n번)에 그 경우가 나온 도수를 k회 모아 **도수의 분포**(막대그래프·표)로 보여 줘요.
   - 만든 사람은 "내가 정한 확률 보기"를 켜서 표·그래프에 설정한 확률(점선)을 겹쳐 볼 수 있어요.
4. **우리 학교에 올리기**: 내 학교·학년도에 올라가요. 한 사람이 10개까지 올려 둘 수 있어요.
5. **우리 학교 실험 판정하기**: 같은 학교 친구들이 올린 실험 목록에서 골라 던져 보고, "같다 / 같지 않다"를 **한 번만** 제출해요. 제출한 뒤에야 친구들의 누적 결과(명수·%)가 보여요. (실험을 한 번 이상 던져야 제출할 수 있어요)
   - 내가 올린 실험은 내가 판정할 수 없고, 누적 결과는 바로 볼 수 있어요.
   - 목록에서 "링크 복사"를 누르면 `/probability/sim/?e=실험번호` 주소를 복사해요. 이 주소로 들어오면 바로 그 실험이 열려요.

## 정답(확률)은 서버에만 있어요
올린 실험의 확률은 서버에만 저장되고, 목록·실험 화면으로는 **내보내지 않아요.** 친구들의 던지기도 서버가 대신 던져서 결과만 돌려줘요.
그래서 브라우저 개발자 도구로도 정답을 알 수 없어요. (만든 사람 자신의 컴퓨터에서 하는 실험은 서버 없이 브라우저에서 던져요.)

## API (`/api/sim`, 모두 POST + JSON, 본문의 `act`로 구분)

| act | 보내는 값 | 돌려주는 값 |
|---|---|---|
| `publish` | year, school, uid, nick, tool, cases[], w[] | `{ id }` |
| `list` | year, school, uid | `{ items }` (최근 50개) |
| `get` | id, uid | `{ item }` |
| `roll` | id, n | `{ r }` — 경우 번호를 한 글자씩 이은 문자열 |
| `rollk` | id, n, k, pick | `{ c }` — 한 회마다 pick 경우의 도수 k개 |
| `vote` | id, uid, choice(`e`=같다 · `n`=같지 않다) | `{ tally, my }` |
| `remove` | id, uid (관리자는 헤더 `x-admin-key`) | `{ ok }` |

- 저장 위치(Redis): `sm:e:<id>`(실험 본문) · `sm:idx:<학년도>:<학교>`(목록) · `sm:v:<id>`(집계) · `sm:vu:<id>`(누가 판정했는지) · `sm:own:<uid>`(내가 올린 것). 약 13개월 뒤 저절로 지워져요.
- 학교·학년도마다 최대 100개 (넘으면 오래된 것부터 지워요).
- 도구·경우 이름과 별명은 서버가 금지어를 검사해요. 같은 IP에서 던지기는 1분에 600번, 올리기·판정은 60번까지예요.

## 잘못 올라온 실험 지우기 (관리자)
`RD_ADMIN_KEY`(강 건너기와 같은 암호)로 지울 수 있어요. 실험 번호는 목록 화면의 "링크 복사"로 나오는 주소 끝에 있어요.

```
curl -X POST "https://mtryu-lab.vercel.app/api/sim" -H "Content-Type: application/json" -H "x-admin-key: 비밀문구" -d '{"act":"remove","id":"실험번호"}'
```

## 서버가 확인하는 것, 못 하는 것
- 도구·경우 이름(금지어·길이·중복), 경우 수, 확률 값, 학년도·학교(등록된 것만)는 서버가 확인해요.
- 판정은 기기별 익명 번호(uid)로 한 번만 받아요. 하지만 같은 사람이 브라우저 저장 데이터를 지우고 새 정보로 들어오면 다시 판정할 수 있어요. (로그인이 붙으면 막을 수 있어요)
- 던진 결과는 서버의 암호용 난수로 만들어져요.

## 고칠 때 참고
- 경우 최대 개수(8개)는 색 팔레트(검증된 8색)에 맞춘 거예요. 늘리려면 `index.html`의 `SC`·`.k0~.k7`·`MAX_CASES`와 `api/_simlib.js`의 `MAX_CASES`를 같이 고쳐요.
- 던지기 상한은 `index.html`의 `MAX_ROLL`·`MAX_REP_*`와 `api/_simlib.js`의 같은 이름 값이 서로 같아야 해요.
