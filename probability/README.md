# 강 건너기 (Roller Derby) · 확률 실험실

두 학생이 토큰 12개를 1~12 칸에 나눠 놓고, 주사위 두 개의 합이 나온 칸의 토큰이 (위에서부터) 부서지는 게임입니다.
먼저 모두 부순 사람이 이기고, 굴린 횟수가 학교별 순위표에 자동으로 기록됩니다. 순위표는 10명씩 쪽을 넘겨 전체를 볼 수 있고, 이름으로 찾을 수도 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 전체(화면·애니메이션·순위표). 이 파일만 열어도 실행돼요. |
| `api/scores.js` | 순위 기록을 모든 컴퓨터가 함께 쓰게 해 주는 Vercel 서버 함수 |
| `api/config.js` | 학년도·학교 목록을 서버에 저장하는 함수 (관리자 모드에서 사용) |
| `api/schools.js` | 관리자 모드에서 학교 이름을 치면 전국 학교 목록을 보여 주는 함수 (나이스 개방포털 사용) |
| `api/_lib.js` | 위 두 함수가 같이 쓰는 도구 (따로 건드릴 것 없어요) |

## 1. 먼저 컴퓨터에서 돌려 보기

`index.html`을 더블클릭해서 브라우저로 열면 바로 게임이 돼요.
이때 순위는 **그 컴퓨터에만** 저장되고, 순위표 오른쪽 위에 "이 컴퓨터 기록"이라고 표시돼요.

## 2. 관리자 모드 (학년도·학교 추가)

처음에는 **2026학년도 · 선운중학교**만 보여요. 더 늘리려면:

1. 첫 화면 오른쪽 위의 **관리자**를 눌러요.
2. 암호를 입력해요.
   - 서버가 연결돼 있으면 Vercel 환경 변수 `RD_ADMIN_KEY`에 정해 둔 암호예요.
   - 서버가 없으면(컴퓨터에서만 열어 볼 때) **처음 입력한 암호가 그 컴퓨터의 관리자 암호**가 돼요.
3. 학년도·학교를 추가하거나 ×로 지우고 **저장하기**를 눌러요.
   - 서버가 연결돼 있으면 모든 컴퓨터에 똑같이 보여요. 서버가 없으면 그 컴퓨터에만 저장돼요.

**학생도 학교를 추가할 수 있어요**: 첫 화면의 "학교 이름 검색"에 두 글자 이상 쓰면 나이스에서 찾은 학교가 아래에 뜨고, 눌러서 추가해요. 서버가 나이스에서 실제로 있는 학교인지 확인하고 등록하므로 엉뚱한 이름은 들어오지 못해요. 같은 IP에서 분당 120번 검색, 10분에 10번 추가, 서버 전체로 하루 5000번까지만 나이스를 호출하고, 학교는 200개까지 등록돼요. 학년도는 관리자만 정해요. (`NEIS_KEY`가 있어야 해요.)

**학교 이름 자동 검색 (선택)**: 학교 칸에 두 글자 이상 쓰면 전국 학교가 목록으로 떠요. 같은 이름의 학교를 또 추가하면 `선운중학교(경기도)`처럼 지역이 붙어요.
1. [나이스 교육정보 개방포털](https://open.neis.go.kr)에서 회원가입 후 인증키를 발급받아요.
2. Vercel 환경 변수 `NEIS_KEY`에 그 키를 넣고 다시 배포해요.
키가 없으면 검색 대신 이름을 직접 써서 추가하면 돼요. (키는 서버에서만 쓰이고 학생 화면에는 나오지 않아요.)

학교 이름이 나이스 정식 이름으로 들어와서 제각각으로 갈라지지 않아요.
목록에서 지워도 이미 저장된 순위 기록은 그대로 남아요. (다시 추가하면 다시 보여요.)

**순위 기록 지우기**: 관리자 모드 아래쪽에서 학년도·학교를 고르고 "전체 순위 삭제"를 두 번 누르면 그 순위 기록이 모두 지워져요. (되돌릴 수 없어요.)

`index.html` 맨 위 `CONFIG`의 `years`, `schools`는 서버·저장된 목록이 없을 때 쓰는 **처음 값**이에요.

## 3. 학교 전체 순위표 켜기 (Vercel)

1. 이 폴더(`index.html`, `api/`)를 실험실 저장소에 넣고 Vercel에 배포해요. (`api/scores.js`는 따로 설정할 것 없이 자동으로 서버 함수가 돼요.)
2. Vercel 프로젝트의 **Storage / Marketplace**에서 **Upstash Redis**(무료 플랜)를 만들어 프로젝트에 연결해요.
   연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` (또는 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`) 환경 변수가 자동으로 들어가요.
3. 환경 변수 `RD_ADMIN_KEY`에 관리자 암호를 적어요. (관리자 모드 로그인에 필요해요.)
4. 다시 배포하면 끝! 순위표 오른쪽 위가 "학교 전체 기록"으로 바뀌어요.

### 잘못된 기록 지우기 (선택)

`RD_ADMIN_KEY`로 잘못된 기록도 지울 수 있어요. 기록의 `id`는 Upstash 데이터 화면에서 볼 수 있어요.

```
curl -X DELETE "https://내주소/api/scores?year=2026&school=선운중학교&id=기록id" -H "x-admin-key: 비밀문구"
```

## 규칙과 참고

- 토큰은 칸마다 쌓이고, 주사위 합이 나온 칸의 **맨 위 토큰부터** 부서져요. 부서진 토큰은 조각난 모양으로 제자리에 남아서 처음 배치를 알 수 있어요.
- 주사위 두 개의 합은 2~12라서 **1번 칸 토큰은 영원히 안 부서져요.** 한 명만 1번 칸에 놓으면 그 사람은 이길 수 없고, 둘 다 놓으면 "아무도 끝낼 수 없어요" 화면이 나와요. (기록되지 않아요)
- 두 사람이 같은 굴림에서 동시에 끝나면 무승부이고, 둘 다 같은 횟수로 기록돼요.
- 순위는 굴린 횟수가 적을수록 높고, 같으면 먼저 기록한 사람이 위예요.
- 학교·학년도마다 최대 2만 개 기록까지 저장해요. (한 줄이 약 150바이트라 저장 용량 부담은 거의 없어요.)
- 서버가 기록의 공정성까지 검증하지는 않아요. (이름, 횟수, 배치가 말이 되는지만 확인해요.)
