# 골드핑거 · 확률 실험실

20문제(문제당 5점)를 **아는 문제는 맞히고 나머지는 찍을 때**, 찍는 방법에 따라 점수가 어떻게 달라지는지 알아보는 실험이에요.
정답은 1~5번이 각각 정확히 4개씩 들어 있어요. 어느 방법으로 찍어도 평균은 `20 + 4 × 아는 문제 수`점이에요.

## 하는 일

화면은 두 쪽이에요.

- **시험 화면**: 아는 문제 수(모두 찍기 · 5 · 10 · 15문제)를 고르면 OMR 답안지에서 앞 번호(5문제면 1~5번)가 분홍색으로 잠겨요. 아는 문제는 정답으로 채점돼요. 찍는 방법은 **내맘대로**(무작위)와 **한 번호**(상자 안에서 찍을 번호를 골라요) 두 가지예요. 고르면 나머지 문항에 답이 적히고, 칸을 눌러 직접 바꿀 수도 있어요. 버튼은 **시험 보기**와 **초기화** 둘뿐이에요. 시험 보기를 누르면 서버가 채점해서 OMR에 맞은 문항(빨간 동그라미)과 틀린 문항(빨간 빗금), 정답 칸(빨간 테두리)을 보여 주고, 점수는 곧바로 순위에 올라가요.
- **순위표 화면**(`#rank`): 아는 문제 수별 순위표, 그 아래에 점수 분포(내맘대로와 한 번호를 컴퓨터가 각각 1000번 본 결과), 맨 아래에 생각해 볼 문제가 있어요. 순위표에는 별명, 점수, 그리고 **찍은 모양**(20문제의 마킹)이 나와요. 점수가 높을수록 위, 같은 점수는 공동 순위(1·2·2·4위)예요. 기본은 내 학교·내 반이고, 다른 학교나 반을 골라 볼 수도 있어요. 학년도는 날짜로 저절로 정해져요(3월 1일에 바뀌어요). 정답은 늘 1~5번이 4개씩이에요.

## 순위는 서버가 직접 채점해요

정답은 서버(`api/goldfinger.js`)가 시험을 볼 때 만들어요. 학생 화면은 정답을 모르는 채로 **아는 문제 수와 마킹한 답**만 보내고, 아는 문제 칸은 서버가 정답으로 채워서 채점해요. 그래서 화면을 고쳐서 점수를 꾸밀 수 없어요. 찍는 방법 이름(내맘대로 · 한 번호)은 서버가 마킹을 보고 정해요.
순위표에는 **별명**(내 정보)과 점수, 찍은 모양만 보여요. 실명·학번은 올라가지 않아요.

- 내 정보(학교·학년·반·별명·익명 번호)가 있어야 시험을 볼 수 있어요. 없으면 내 정보 입력창이 떠요.
- 같은 사람(익명 번호)이 같은 학교·학년도·아는 문제 수에 두 번 보면 새로 만들지 않고 **이미 본 기록**을 보여 줘요. 관리자 화면에서 기록을 지우면 다시 볼 수 있어요.
- 관리자 화면의 **테스트 모드**에서는 서버에 아무것도 보내지 않아요. 기록은 이 컴퓨터에만 따로 모이고, 여러 번 볼 수 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `probability/goldfinger/index.html` | 화면 전체(시험 화면·OMR 답안지·순위표 화면) |
| `api/goldfinger.js` | 시험 보기(서버가 정답을 만들어 채점해 저장) · 내 기록 읽기 |
| `api/coin.js` | 순위표 읽기·이름 찾기·반별 보기·기록 삭제. 동전 실험실과 같은 함수에 `gf0` · `gf5` · `gf10` · `gf15` 게임으로 들어 있어요 (쓰기는 `/api/goldfinger`만 받아요) |
| `api/admin.js` · `admin/index.html` | 관리자 화면의 골드핑거 메뉴(접속 분석·기록 관리) |

기록은 강 건너기·동전 실험실과 같은 Upstash Redis에 `cn:gf<아는 문제 수>:<학년도>:<학교>` 키로 저장돼요. **새로 넣을 환경 변수는 없어요.**

## 기록 관리

관리자 화면(`/admin/`) → 확률 실험실 → **골드핑거** 아래에서 아는 문제 수별로 기록을 보고, 한 건·선택·전체 삭제하거나 반을 바꿀 수 있어요. 접속 분석에는 골드핑거가 따로 집계돼요.
