# 골드핑거 · 확률 실험실

20문제(문제당 5점)를 **아는 문제는 맞히고 나머지는 찍을 때**, 찍는 방법에 따라 점수가 어떻게 달라지는지 알아보는 실험이에요.
정답은 1~5번이 각각 정확히 4개씩 들어 있어요. 어느 방법으로 찍어도 평균은 `20 + 4 × 아는 문제 수`점이에요.

## 하는 일

- **연습**: 아는 문제 수(모두 찍기 · 5 · 10 · 15문제), 찍는 방법(내맘대로 · 규칙적 · 한 번호), 정답 배치(각 번호 4개씩 · 완전 무작위)를 골라 시험 1번을 봐요. 결과는 **OMR 답안지**로 나와요. 마킹이 채워진 뒤에 맞은 문항은 빨간 동그라미, 틀린 문항은 빨간 빗금이 찍히고 정답 칸에 빨간 테두리가 둘러져요.
- **반복 실험**: 같은 조건으로 100 · 1000 · 10000번 반복해서 점수의 상대도수 분포를 봐요. 이론 평균(금색 점선)과 실제 평균(분홍 ▲)이 함께 나와요. "세 가지 찍는 방법 비교"는 세 방법을 각각 1000번씩 돌려 같은 눈금으로 나란히 보여 줘요.
- **순위 도전**: 아는 문제 수마다 **한 번만** 도전할 수 있고, 순위표는 아는 문제 수(모두 찍기 · 5 · 10 · 15)별로 따로 있어요. 점수가 높을수록 위, 같은 점수는 공동 순위(1·2·2·4위)예요. 기본은 내 학교·내 반이고, 다른 학교나 다른 반을 골라 볼 수도 있어요. 학년도는 날짜로 저절로 정해져요(3월 1일에 바뀌어요).

## 순위는 서버가 직접 채점해요

순위에 올라가는 시험은 화면이 아니라 서버(`api/goldfinger.js`)가 만들어요. 학생이 정하는 건 **아는 문제 수와 찍는 방법**뿐이고, 정답 배치·아는 문제·찍는 답·점수는 서버가 정해서 기록해요. 그래서 화면을 고쳐서 점수를 꾸밀 수 없어요.
순위표에는 **별명**(내 정보)과 점수, 찍는 방법만 보여요. 실명·학번은 올라가지 않아요.

- 내 정보(학교·학년·반·별명·익명 번호)가 있어야 순위에 도전할 수 있어요. 없으면 연습과 반복 실험만 돼요.
- 같은 사람(익명 번호)이 같은 학교·학년도·아는 문제 수에 두 번 도전하면 새로 만들지 않고 **이미 한 기록**을 보여 줘요. 기록을 지우면 다시 도전할 수 있어요.
- 관리자 화면의 **테스트 모드**에서는 서버에 아무것도 보내지 않아요. 기록은 이 컴퓨터에만 따로 모이고, 여러 번 도전할 수 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `probability/goldfinger/index.html` | 화면 전체(연습·반복 실험·OMR 답안지·순위표) |
| `api/goldfinger.js` | 순위 도전(서버가 시험을 만들어 채점해 저장) · 내 기록 읽기 |
| `api/coin.js` | 순위표 읽기·이름 찾기·반별 보기·기록 삭제. 동전 실험실과 같은 함수에 `gf0` · `gf5` · `gf10` · `gf15` 게임으로 들어 있어요 (쓰기는 `/api/goldfinger`만 받아요) |
| `api/admin.js` · `admin/index.html` | 관리자 화면의 골드핑거 메뉴(접속 분석·기록 관리) |

기록은 강 건너기·동전 실험실과 같은 Upstash Redis에 `cn:gf<아는 문제 수>:<학년도>:<학교>` 키로 저장돼요. **새로 넣을 환경 변수는 없어요.**

## 기록 관리

관리자 화면(`/admin/`) → 확률 실험실 → **골드핑거** 아래에서 아는 문제 수별로 기록을 보고, 한 건·선택·전체 삭제하거나 반을 바꿀 수 있어요. 접속 분석에는 골드핑거가 따로 집계돼요.
