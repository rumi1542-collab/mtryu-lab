# 달랑베르를 이겨라 · 확률 실험실

달랑베르(d'Alembert)는 동전 2개를 던질 때 앞면이 0개, 1개, 2개 나오는 경우가 모두 똑같이 일어난다고 생각했어요.
그래서 돌 12개를 앞면 0·1·2개 칸에 **4개씩** 똑같이 놓습니다. 학생(2P)은 돌 12개를 마음대로 나눠 놓고, 동전 2개를 던져서 달랑베르를 이기는 게임이에요.

- 동전 2개를 던져 앞면이 나온 개수의 칸에서, 두 쪽 모두 맨 위 돌 1개가 팡 터지며 강을 건너요. 터진 자리에는 자국이 남아요.
- 돌 12개를 먼저 모두 건넌 쪽이 이겨요. 같은 던지기에서 둘 다 끝나면 무승부예요.
- 학생이 이긴 판만, **몇 번 던져서 이겼는지**가 학교 순위에 올라가요 (적을수록 위, 같은 횟수는 공동 순위·최근 기록이 위).
- 순위표에는 순위, 별명, 던진 횟수, 처음 배치(칸별 막대그래프)가 보여요. 기본은 내 학교·내 반이고, 학교·반을 골라 다른 곳도 볼 수 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `probability/dalembert/index.html` | 화면 전체 (배치·게임·순위 보기). `#rank` 주소로 순위 보기 화면이 열려요. |
| `api/coin.js` | 동전 실험실과 같은 순위 서버. `game=dalembert`로 저장해요. 던진 결과(`seq`)와 처음 배치(`pl`)를 서버가 달랑베르(4·4·4)와 다시 겨뤄 보고, 학생이 마지막 던지기에서 먼저 다 건넌 판만 받아요. |
| `api/_lib.js` | 공동 순위 계산에 `dalembert`(던진 횟수)를 추가했어요. |
| `api/admin.js`, `admin/index.html` | 관리자 화면에 기록 관리·접속 분석·기록 수 표를 추가했어요. |
| `api/hit.js`, `lab-bar.js` | 접속 분석에서 이 화면을 `dalembert`로 구분해요. |

내 정보(`me-sync.js`, `lab-bar.js`)의 별명이 2P 이름으로 자동으로 들어가고, 기록에는 별명과 학년·반만 올라가요. 학년도는 날짜로 자동 결정돼요.
서버가 없거나 테스트 모드일 때는 기록이 이 컴퓨터에만 저장돼요. 새로 넣을 환경 변수는 없어요.
