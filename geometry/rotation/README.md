# 회전체 탐구 · 대수 기하 실험실 (/geometry/rotation/)

평면도형을 한 바퀴 돌려 만든 입체도형을 탐구하는 활동이에요. 한 파일(`geometry/rotation/index.html`)로 이루어져 있고, 외부 라이브러리 없이 캔버스로 입체를 그려요.

## 세 가지 활동
| 활동 | 내용 | 서버 |
|---|---|---|
| 회전체 문제 | 평면도형을 보고 알맞은 회전체를 4개 중에서 골라요. 회전시켜 확인하고, 레벨마다 정해진 순서로 풀어요(앞 문제를 풀어야 다음 문제가 열려요). | 없음 (진행은 이 브라우저에 저장) |
| 단면 문제 | 회전체를 평면으로 자르면 어떤 단면이 나올까요? 축에 수직인 단면의 경계는 항상 원, 축을 포함하는 단면은 선대칭도형(모두 합동) — 교과서 성질을 그대로 따라요. | 없음 |
| 나만의 회전체 만들기 | 격자점으로 평면도형을 그려 회전체를 만들고 우리 학교에 올려요. 친구들은 회전체만 보고 원래 도형을 그려 맞히거나 ‘도형 확인하기’를 눌러 확인해요. | `api/rot.js` |

교사 모드(회전체 문제·단면 문제 화면 아래 작은 링크)를 켜면 모든 문제가 열려요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `geometry/rotation/index.html` | 화면 전체 |
| `api/rot.js` | 올리기·목록·도전·삭제를 처리하는 Vercel 서버 함수 |
| `api/_rotlib.js` | 도형 검사와 ‘같은 입체인지’ 비교 (화면 안의 같은 코드와 똑같아요) |

학교·학년도 목록(`/api/config`), 저장소(Upstash Redis), 이름 검사(`api/_names.js`), 내 정보(`me-sync.js`, `lab-bar.js`)는 확률 시뮬레이터와 **같은 것**을 써요. 새로 넣을 환경 변수는 없어요.

## 나만의 회전체 · 규칙
- 도형은 정수 격자점 `[r, z]`(r: 축에서 떨어진 거리 0~5, z: 0~8)을 이은 닫힌 다각형(3~14개 꼭짓점)이에요. 선이 서로 만나거나 겹치면 안 되고, 축의 오른쪽(r ≥ 0)에만 그려요. 축에서 떨어진 도형도 돼요(속이 빈 회전체).
- **속이 채워지지 않은 선으로 된 도형**으로 봐요. 그래서 비교도 선으로 해요: 회전축 위의 변은 빼고, 선분이 같으면 같은 입체로 봐요. 위아래로 옮긴 도형도 같아요.
- 회전체만 보고는 실제 길이를 알 수 없으니 **크기는 달라도 가로·세로 길이의 비가 같으면(닮은 도형이면) 정답**이에요. 축에서 떨어진 도형은 축까지의 거리와 폭·높이의 비가 모두 같아야 해요. (`rotSame`: 가장 먼 거리를 서로 맞춰 정수로 비교)
- 한 기기에서 10개까지 올릴 수 있고, 올린 학생이 자기 것을 지울 수 있어요. 관리자(`RD_ADMIN_KEY`)는 목록 맨 아래 ‘관리자’에서 암호를 넣어 어느 것이든 지워요.
- 맞히기 화면의 [💡 시작점 힌트]: 힌트 1·2·3을 차례로 누르면 원래 도형의 꼭짓점 3개가 반짝여요(① 축에서 떨어진 가장 아래 꼭짓점 → ② 거기서 가장 먼 꼭짓점 → ③ 앞의 두 점에서 가장 먼 꼭짓점). 힌트는 정답 조건이 아니라 도움말이고, 서버에는 기록하지 않아요.
- 같은 회전체에는 기기당 처음 도전한 결과만 기록돼요 (다시 그려 봐도 되지만 기록은 그대로).
- 원래 도형은 회전체를 그리는 데 꼭 필요해서 목록 데이터에 들어 있어요. 화면은 ‘도형 확인하기’ 전까지 보여 주지 않지만, 개발자 도구로는 볼 수 있어요.

## API (`/api/rot`, 모두 POST + JSON, 본문의 `act`로 구분)
| act | 보내는 값 | 돌려주는 값 |
|---|---|---|
| `publish` | year, school, uid, nick, gr, cl, pts | `{ id }` |
| `list` | year, school, uid | `{ items }` (최근 순 60개) |
| `get` | id, uid | `{ item }` |
| `guess` | id, uid, pts | `{ ok, already }` |
| `remove` | id, uid (관리자는 헤더 `x-admin-key`) | `{ ok }` |
| `adminping` | 헤더 `x-admin-key` | `{ ok }` |

저장 위치(Redis): `rt:e:<id>`(본문) · `rt:idx:<학년도>:<학교>`(목록) · `rt:g:<id>`(도전 기록) · `rt:own:<uid>`(내가 올린 것). 약 13개월 뒤 저절로 지워져요.
